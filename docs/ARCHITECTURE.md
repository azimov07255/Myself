# Kunlik tizim: tuzilma (qisqacha)

Ilova **bitta `index.html`** (PWA), lekin manba kod `src/` papkasida mavzuli fayllarga bo'lingan.
Sayt (GitHub Pages) `tracker/index.html` ni beradi; server qismi Supabase (kirish, ma'lumot, Edge Functions) va Gemini.

## Ish tartibi
1. **Faqat `src/` ni tahrirla** (`src/js/*.js`, `src/css/*.css`, `src/index.template.html`).
2. `python3 tools/build_app.py` → `tracker/index.html` yig'iladi.
3. `bash tests/run_all.sh` → hamma test (birinchi bo'lib `src/` va `index.html` bir xilligini tekshiradi).
4. Yangi versiya chiqarish: `src/js/01-yadro.js` da `APP_VER` ni oshir (YYYY.MM.DD-N), `python3 tools/make_zips.py` (paketlarni yig'adi). Zipning ichidagi hamma narsani, ayniqsa **`version.json`** ni, GitHub'ga yukla: ilova shu fayl orqali yangi versiya borligini biladi.
`index.html` ni qo'lda tahrirlama: keyingi yig'ishda ustidan yoziladi (test buni ushlaydi).
Agar tasodifan qo'lda tahrirlagan bo'lsang: `python3 tools/split_app.py` o'zgarishni `src/` ga qaytaradi.
