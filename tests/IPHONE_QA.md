# iPhone sinov ro'yxati (5-10 daqiqa)
Brauzerda tekshirib bo'lmaydigan joylar. Ilovani "Bosh ekranga qo'shish" orqali o'rnatib, bosh ekrandagi ikonkadan oching.

## Sinxron va zaxira
- [ ] Sozlama → Diagnostika: "Server nusxasi (rev)" raqam ko'rsatadi, "O'rnatilgan ilova: ha"
- [ ] Ikki qurilmada (telefon + kompyuter) turli joyga vazifa qo'shing → ikkalasida ham ko'rinadi (ilovani yopib-ochgach)
- [ ] Sozlama → Avtomatik zaxiralar → "Zaxiralarni ko'rsat": kamida bitta qator

## Formalar
- [ ] Univer → Topshiriq / Imtihon: sana va vaqt maydonlari ustma-ust tushmaydi
- [ ] Zal → Abonement formasi: sanalar to'g'ri joylashadi

## Audio
- [ ] Audio yuklash → ijro → ekranni qulflash → qulf ekranida polosani surish ishlaydi
- [ ] Mini-pleyer: ekran bo'ylab suriladi, chetga tashlansa doiraga aylanadi, bosilsa ochiladi

## AI
- [ ] AI chat: klaviatura chiqqanda oyna siljimaydi, orqadagi sahifa surilmaydi
- [ ] 🎤 ovozli kiritish (mikrofon ruxsati so'raydi)
- [ ] Ovqat rasmi yuborish
- [ ] Writing / Speaking tekshiruvi

## Mushaf (Qur'on → 📖 Mushaf)
- [ ] Birinchi ochilishda matn yuklanadi (internet kerak), keyin internetsiz ham ochiladi
- [ ] Sahifa ekranga sig'adi, qatorlar bosma mushafdagidek (3-sahifa: "إِنَّ ٱلَّذِينَ كَفَرُوا۟" bilan boshlanadi)
- [ ] Chapdan o'ngga surish = keyingi sahifa; ekran chetidan surganda iOS "orqaga" qimirlamaydi
- [ ] Oyatni uzoq bosish → pastdan oyna chiqadi (iOS'ning o'z "nusxalash" oynasi chiqmasligi kerak); rang tanlash ishlaydi
- [ ] Izoh yozish: klaviatura chiqqanda oyna yopilmaydi, matn ko'rinadi
- [ ] 🧠 Sinov: yashirilgan so'zga tegsang ochiladi, "Bildim/Qisman/Bilmadim" chiqadi
- [ ] 236-sahifa (12:11) va 525-sahifa (52:37): so'zlar belgisi bilan to'g'ri chiqadi

## Yo'l (Bugun → daraja kartasi)
- [ ] Bugun ekranida sana ostida daraja kartasi bor, ustiga bossang "Yo'l" ekrani ochiladi
- [ ] Yo'l ekrani butun balandlikda silliq aylanadi, orqadagi sahifa qimirlamaydi
- [ ] Topshiriq bajarilganda "+25 XP" tugmasi chiqadi, bosganda konfetti/xabar chiqadi
- [ ] Do'konda "Olish" bosilganda tasdiq so'raydi, mukofot "Olingan mukofotlar"da ko'rinadi, ↩ bilan bekor bo'ladi
- [ ] Mukofot qo'shish: emoji, nom, tanga yozilganda iPhone klaviaturasi oynani yopmaydi
- [ ] Qur'on bo'limi: yuqorida "Qur'on | Ibodat" tugmalari, tagida shu guruhning bo'limlari

## AI kun rejasi
- [ ] AI suhbatda "ertalabdan kechgacha rejamni tuzib ber" desang, vaqt bloklari kartasi chiqadi (30 soniyadan oshmasa kerak)
- [ ] Karta ekranga sig'adi, "Rejaga qo'sh" bosilgach Bugun ekranida jadval paydo bo'ladi
- [ ] Qo'shimcha ishlar uchun Telegram/push eslatma kelishi (Sozlama → Eslatmalar → reja bloklari yoqilgan bo'lsin)

## Yangi versiya xabari
- [ ] Yangi versiya yuklangandan keyin eski versiyada ilovani ochsang (yoki fonga o'tib qaytsang) tepada "🔄 Yangi versiya tayyor" chizig'i chiqadi
- [ ] "Yangilash" bosilganda ilova qayta yuklanadi va yangi versiya raqami Sozlama → Diagnostika'da ko'rinadi
- [ ] "✕" bosilsa chiziq yo'qoladi; Diagnostika'dagi "Yangilanishni tekshirish" holatni aytadi

## IELTS materiallari
- [ ] O'qish → IELTS → Materiallar: maqola matnini qo'yish (iPhone'da kattaroq matn qo'yilganda sekinlashmaydi)
- [ ] Podkast: transkript (SRT yoki [01:23] qatorlar) + audio fayl tanlash (Fayllar ilovasidan); audio chaladi, subtitr qatori vaqt bo'yicha ajraladi
- [ ] Qator oldidagi vaqtni bossang audio o'sha joyga o'tadi; 0.75× / 1.25× tezlik; "⟲ gap" bitta qatorni takrorlaydi
- [ ] Ajratilgan so'zni bossang karta chiqadi; 🔊 talaffuz (iPhone ovozi yoqilgan bo'lsin); "Lug'atga qo'shish"
- [ ] Lug'at → "Gapni to'ldir" rejimi ishlaydi; kunlik yangi so'z limiti ishlaydi
- [ ] IELTS Bosh va Maqsad: IELTS tayyorgarligi + Qur'on hifzi paneli, telefon kengligiga sig'adi

## IELTS: AI mashq, xatolar daftari, diktant
- [ ] IELTS yuqorida 4 ta tab (Bosh, Lug'at, Materiallar, Mashq); Mashq ichida 4 ta bo'lim, ikkinchi qator siljimasdan sig'adi
- [ ] AI mashq → "Mashq yaratish": matn va 8 savol chiqadi; javob berib "Tekshirish" bosiladi (tugma ekran pastida bosiladi, hech narsa yopib turmaydi)
- [ ] Writing yoki Speaking'ni AI bilan tekshirtirib saqlagandan keyin xatolar "Xatolar daftari"da paydo bo'ladi; "Xatolarim bo'yicha mashq" ishlaydi
- [ ] Lug'at kartochkasi → "Gap tuz va AI tekshirsin"
- [ ] Podkast + audio: qator yonidagi ✍ tugmasi, eshit → yoz → tekshir; xato so'zlarni bosib lug'atga qo'sh
- [ ] Suhbat sarlavhasida "AI: N/40 bugun"

## IELTS: ovoz, talaffuz, transkript
- [ ] Lug'at kartochkasi: 🔊 talaffuz; "🗣 US / 🗣 UK" tugmasi ovozni almashtiradi (iPhone: Samantha / Daniel); gap yonidagi 🔊 butun gapni o'qiydi
- [ ] Materiallar → maqola: "🔊 O'qib ber" gapma-gap o'qiydi; paragraf ajraladi (so'z ajralishi iPhone'da ishlamasligi mumkin, bu normal)
- [ ] Podkast + audio (matnsiz): "Transkript qilish" → matn paydo bo'ladi; chalinganda so'zlar birga ajralib yuradi
- [ ] Transkriptdan keyin "AI bilan tahlil" va diktant ishlaydi
- [ ] Sekin rejim (🐢) tezlikni kamaytiradi

## IELTS: tahlil, tahrirlash, bulutdagi audio
- [ ] Kompyuterda podkast + audio qo'shgin, telefonda o'sha materialni och: audio bulutdan yuklanadi va chaladi (internet bilan)
- [ ] Materiallar ro'yxatida ✏️: nom, matn, audio almashtirish; audioni telefondan tanlash (Fayllar ilovasi) ishlaydi
- [ ] "AI bilan tahlil": darajani tanla (B1+/B2+/C1+); natijada B1..C2, chunk va grammar filtrlari bor
- [ ] "☑ Hammasini belgilash" va "⚡ Ko'ringanlarning hammasini qo'shish", keyin "↩ Bekor qilish"
- [ ] Matnda so'zlar daraja rangida chiziladi; grammatik tuzilma ichidagi so'z bosilsa grammar kartochkasi ochiladi
- [ ] Transkript qatorini tuzatish (✏️ → "Transkript qatorlarini tuzatish")

## IELTS o'qish: joy, belgilash
- [ ] "O'qib ber": o'qilayotgan gap yashil fonda; pauza → "Davom ettirish" shu gapdan boshlaydi; "Boshidan" ishlaydi
- [ ] Matnda so'zni bossang karta chiqadi, kartada "Shu gapdan o'qib ber"
- [ ] 2–3 so'zni barmoq bilan belgila (so'zni uzoq bosib, tutqichlarni sur): pastda "✨ Ma'nosi" paneli chiqadi va ma'no darhol keladi
- [ ] Tahlil natijalarida "Hammasini belgilash" bosilganda sahifa pastga/tepaga sakramaydi
- [ ] Podkastni to'xtatib yopib qayta ochsang, o'sha joydan davom etadi
- [ ] Grammar tuzilmasi ichidagi so'zlar oddiy matn kabi (katak emas), och binafsha fonda

## Yangi: statistika, xarita, murabbiy, o'yinlar, moslash

- [ ] Bugun → 🧭 AI murabbiy: "Haftalik reja tuz" (yakshanba), ertasiga bugungi vazifalar chiqadi
- [ ] Materiallar → forma → 🔗 Olish: BBC Learning English kabi sahifa havolasi
- [ ] IELTS → Lug'at → 🎮 o'yinlar: uchala o'yin; Imlo'da 🔊 ovozi
- [ ] Podkast (audio + oddiy matn) → 🎯 Moslash, keyin chalinganda so'zlar birga yuradi

## Pul va Odat yangiliklari
